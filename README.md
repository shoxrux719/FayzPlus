# Fayz Plus — фикр-мулоҳаза сайти

QR код орқали очиладиган, мобил қурилмаларга мос беморлар сўровномаси. Асосий тил — ўзбекча кирилл; русча ва инглизча интерфейс ҳам бор.

Ҳар бир саҳифа юкланишида, жумладан Ctrl+R билан қайта юкланганда ҳам, 3–4 сониялик кириш анимацияси кўрсатилади. Уни ўтказиб юбориш мумкин. `prefers-reduced-motion` ёқилганида қисқа, содда пайдо бўлиш эффекти ишлайди.

## Локал ишга тушириш

```bash
npm install
npm run dev
```

Текширув: `npm run build` ва `npm test`.

Калитларсиз `npm run dev` намойиш режимида ишлайди: жавоблар фақат браузер `localStorage` хотирасида сақланади. Агар `.env.local` да Telegram ёки Supabase калитлари ва `VITE_DELIVERY_CONFIGURED=true` бўлса, локал Vite сервер ҳам `/api/feedback` функциясини ишга тушириб, жавобларни ҳақиқатан юборади.

## Нашр қилиш

Лойиҳани Vercel'га импорт қилинг. Build command: `npm run build`; output directory: `dist`. `api/feedback.ts` автоматик сервер функцияси сифатида ишлайди.

Vercel Environment Variables'да `.env.example` файлдаги ўзгарувчиларни киритинг. Камида битта канал керак:

- `TELEGRAM_BOT_TOKEN` ва `TELEGRAM_CHAT_ID`: ҳар бир жавоб администратор чатига юборилади.
- `SUPABASE_URL` ва `SUPABASE_SERVICE_ROLE_KEY`: жавоблар `feedback` жадвалига сақланади. Жадвални яратиш учун [supabase/schema.sql](supabase/schema.sql) ни Supabase SQL Editor'да ишга туширинг.

Иккаласи уланса, ҳар икки канал ишлайди. Ҳеч бири созланмаса, ишлаб чиқариш муҳитида сайт жавобни қабул қилинди деб кўрсатмайди; қайта уриниш хабарини кўрсатади. Махфий калитлар фронтендга чиқарилмайди.

Клиника маълумотлари ва хизматлар [src/config.ts](src/config.ts) да. Шифокорлар рўйхати атайин бўш: тасдиқланмаган исмлар қўшилмаган. Исмларни `doctors` рўйхатига `{ id, name }` шаклида киритинг.

QR кодлар учун бир хил сайт манзилига параметрлар қўшинг: `?branch=chinobod&doctor=doctor01&source=reception`. Улар жавоб билан бирга сақланади. `branch`, `doctor`, `source` қийматлари 60 белгидан ошмаслиги, ҳарф, сон, `_` ёки `-` дан ташкил топиши керак.

Сўровнома такроран юборишни 3 дақиқа давомида шу браузерда чеклайди. Серверда яширин майдон, вақт ва маълумотлар текшируви бор. Бу асосий спам ҳимояси; катта ҳажмли оммавий ишлатишда Vercel rate limiting ёки аналогини қўшиш мақсадга мувофиқ.
